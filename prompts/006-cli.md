# 006 — CLI wiring — read and remap commands

## Requirements

- R01: WHEN `textread <url>` is run, THE SYSTEM SHALL fetch (or use cache), run the
  agent, write `mapping.yaml`, and print a terse verdict line to stdout.
- R02: WHEN `textread <url> --model <alias>` is run, THE SYSTEM SHALL pass that alias
  to `agent.evaluate` instead of the config default.
- R03: WHEN `textread <url> --context <path>` is run, THE SYSTEM SHALL load context
  from `<path>` instead of the configured context file.
- R04: WHEN `textread <url> --refresh` is run, THE SYSTEM SHALL bypass the cache and
  re-fetch from the network.
- R05: WHEN `textread <url> --deep` is run, THE SYSTEM SHALL print the full `Mapping`
  (all fields) to stdout instead of only the verdict line.
- R06: WHEN `textread remap <url>` is run and the URL is not in cache, THE SYSTEM SHALL
  print `[ERROR] No cache entry for <url> — run textread <url> first` and exit with
  code 1.
- R07: WHEN `textread remap <url>` is run and the URL is cached, THE SYSTEM SHALL
  re-run the agent on the cached raw content and overwrite `mapping.yaml`.
- R08: WHEN `textread context show|edit` is run, THE SYSTEM SHALL delegate to the
  `context_group` imported from `context.py`.
- R09: WHEN `textread cache list|path|clear` is run, THE SYSTEM SHALL delegate to the
  `cache_group` imported from `cache.py`.
- R10: WHEN the agent call raises `AgentError`, THE SYSTEM SHALL print `[ERROR] <msg>`
  to stderr and exit with code 1.
- R11: WHEN `FetchBlocked` is raised, THE SYSTEM SHALL print `[WARN] Blocked by
  robots.txt: <url>` to stderr and exit with code 1.
- R12: WHEN `FetchError` is raised, THE SYSTEM SHALL print `[ERROR] Fetch failed:
  <msg>` to stderr and exit with code 1.

## Design

### overview

`cli.py` is the composition root. It imports all modules and wires them into the
Click group hierarchy. No business logic lives here — it orchestrates module calls
in the documented sequence and handles exit codes. The `main` placeholder from
prompt 001 is replaced wholesale.

The terse verdict line format: `{verdict.upper()}  ({score}/100)  {reason}`.
With `--deep`: print the full mapping as YAML.

### modules

- `src/textread/cli.py` — Replaced. Full Click group with `read` (default command),
  `remap`, `context` (subgroup), `cache` (subgroup).
- `tests/test_cli.py` — New file. CliRunner-based integration tests with all
  modules mocked.

### sequence

read_flow:
  1. Load `TextreadConfig` via `config.load()`.
  2. Determine model: `--model` flag > `cfg.default_model`.
  3. Load context: `--context <path>` overrides `context.load(cfg)`.
  4. Call `fetch.pull(url, refresh=refresh, cache=cache_module)` → `FetchResult | None`.
     If None (cache hit): call `cache.get_markdown(url, cfg)` for the cleaned markdown.
     If FetchResult: call `cache.put(url, result, cfg)` then `cache.get_markdown(url, cfg)`
     for the cleaned markdown (raw.md is written by put).
  5. Call `agent.evaluate(url, raw_text, ctx, model)` → `Mapping`.
  6. Call `cache.write_mapping(url, dataclasses.asdict(mapping), cfg)`.
  7. Print verdict line. If `--deep`, print full YAML instead.

remap_flow:
  1. Load config + context (same as steps 1-3 above).
  2. If not `cache.exists(url, cfg)` → print error, `sys.exit(1)` (R06).
  3. `raw = cache.get_markdown(url, cfg)` — read the cleaned markdown, not raw HTML.
  4. `mapping = agent.evaluate(url, raw, ctx, model)`.
  5. `cache.write_mapping(url, dataclasses.asdict(mapping), cfg)`.
  6. Print verdict line (or --deep output).

### degradation

```python
try:
    result = fetch.pull(url, refresh=refresh, cache=cache)
except FetchBlocked as e:
    click.echo(f"[WARN] Blocked by robots.txt: {e}", err=True)
    sys.exit(1)
except FetchError as e:
    click.echo(f"[ERROR] Fetch failed: {e}", err=True)
    sys.exit(1)

try:
    mapping = agent.evaluate(url, raw, ctx, model)
except AgentError as e:
    click.echo(f"[ERROR] {e}", err=True)
    sys.exit(1)
```

## Steps

1. Replace `src/textread/cli.py` with the full implementation:
   - `@click.group()` named `main`, version option from `__version__`.
   - `@main.command(name="read")` (or make the default — use `invoke_without_command`
     pattern with a plain `main` that accepts URL). Actually: implement as
     `@main.command()` named `read`. The user types `textread read <url>` or for
     convenience alias the group to also accept url as argument. Keep it simple:
     use explicit `textread read <url>` for v1 to avoid Click complexity.
   - `@main.command()` named `remap`.
   - `main.add_command(context_group, "context")`.
   - `main.add_command(cache_group, "cache")`.
   - All flags: `--model TEXT`, `--context PATH`, `--refresh`, `--deep`, `--save`
     (--save is wired in prompt 007; declare it here but `pass` on the body for now —
     note the TODO comment).

2. Create `tests/test_cli.py`:
   - All tests use `click.testing.CliRunner`.
   - Mock `fetch.pull`, `agent.evaluate`, `cache.*` at module level with `monkeypatch`.
   - `test_r01_read_prints_verdict` — mock fetch returns FetchResult, mock agent returns
     Mapping with verdict="worth_reading"; invoke `textread read <url>`; assert verdict
     in output.
   - `test_r02_model_flag` — assert agent.evaluate is called with the specified model alias.
   - `test_r03_context_flag` — monkeypatch `context.load` to check path is overridden.
   - `test_r04_refresh_flag` — assert fetch.pull is called with `refresh=True`.
   - `test_r05_deep_flag` — assert full mapping fields appear in output.
   - `test_r06_remap_no_cache` — cache.exists returns False; assert exit code 1 and
     error message.
   - `test_r07_remap_uses_cached_raw` — cache.exists True, get_markdown returns text; assert
     agent is called with that text.
   - `test_r10_agent_error_exits_1` — agent raises AgentError; assert exit 1 and [ERROR].
   - `test_r11_fetch_blocked_exits_1` — fetch raises FetchBlocked; assert exit 1 and [WARN].
   - `test_r12_fetch_error_exits_1` — fetch raises FetchError; assert exit 1 and [ERROR].

3. Run `uv run pytest tests/test_cli.py -v` — all green.
4. Manual smoke test: `uv run textread --help` prints the group with `read`, `remap`,
   `context`, `cache` subcommands listed.
